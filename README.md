## 🚀 Featured Projects

### 🌏 [JanSetu — SIH26042](https://github.com/adityashinde1537/SIH26042-Tribal-Language-Education)

**AI-powered vernacular pedagogy and Hindi → Santhali translation system for mother-tongue-based primary education.**

- Android 9+ app using Kotlin and Jetpack Compose
- Hindi → Santhali translation in **Ol Chiki**
- FastAPI backend with **IndicTrans2 INT8 ONNX**
- Offline translation library using Room / SQLite
- Voice input, TTS support, worksheets, and flashcards
- Built for **Smart India Hackathon 2026**

**Tech:** Kotlin · Jetpack Compose · Python · FastAPI · IndicTrans2 · ONNX Runtime · SQLite · GitHub Actions

[View JanSetu →](https://github.com/adityashinde1537/SIH26042-Tribal-Language-Education)

### 🔤 [Hindi → Santhali TranslationApp](https://github.com/adityashinde1537/TranslationApp)

A full-stack translation prototype connecting an Android interface to an AI-powered FastAPI backend.

- Android UI with Kotlin + Jetpack Compose
- REST API integration with Retrofit
- Hindi `hin_Deva` → Santhali `sat_Olck`
- IndicTrans2-powered translation
- SQLite caching and output validation
- CI with GitHub Actions

**Tech:** Kotlin · Jetpack Compose · Retrofit · Python · FastAPI · IndicTrans2 · ONNX Runtime · SQLite

[View TranslationApp →](https://github.com/adityashinde1537/TranslationApp)
