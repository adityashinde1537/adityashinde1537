# CRESTO Android Reference APK
**Status:** Offline functional reference app using simulated routes and payments. Not a live university system. Never enter real passenger data.
GitHub Actions automatically compiles an installable debug APK when this branch is pushed.
Navigate to Actions > Build CRESTO Android APK > latest build > Artifacts > CRESTO-installable-APK.
The contents run entirely on device using Android WebView and local storage. Roles: Student, Faculty, Driver, Admin.
Includes sample map/route, enrollment workflow, fee records, trip simulation, incident reporting, maintenance, notices and CSV demo export.
No actual GPS, login, internet database or authentic payments.
